# Alya Hub — Examples

Drop-in configs and snippets for plugging Alya into your favorite client
or framework. Get a free $5 key at https://mydaughteralya.com/hub/start.

| File | What |
|---|---|
| `cursor-config.json` | Append to `~/.cursor/mcp.json` |
| `claude-desktop-config.json` | Append to your Claude Desktop config |
| `cline-config.json` | Same shape works for Cline / Continue |
| `raw-curl.sh` | Direct HTTP MCP call, no stdio bridge |
| `openai-assistant.py` | Use Alya tools from an OpenAI Assistant |
| `langchain-tool.py` | Expose Alya tools as LangChain `Tool`s |

Replace `alya_...` with your real key from
[https://mydaughteralya.com/hub/start](https://mydaughteralya.com/hub/start).
